# Money Tree AI — First 30 days

Goal: real visibility (stars, installs, traffic) and honest feedback, not
vanity metrics. Every claim published in this window must trace to the README
or source — see `docs/marketing/social.md`'s notes.

## Week 1 — assets and first push

- Finish and publish the 8-slide Instagram carousel already drafted in
  `scratchpad/mtcarousel/` (README-lead story: problem → research screen →
  Simple/Advanced → indicators → paper strategy testing → honest AI panel →
  open source / no profit promise).
- Post the README rewrite live (this commit) — it's the landing page for
  anyone who clicks through from social, so it has to say the honest
  backtest number before anything else, which it now does.
- X thread (in `social.md`) same day as the Instagram post, cross-link both.

## Week 2 — where the actual audience is

- Reddit posts to r/algotrading, r/Python, r/opensource, r/degiredevs (spaced
  a few days apart, not all at once — each community's rules on self-promo
  differ, read them first). Use the honest "here's what didn't work" framing
  from `social.md` — that community rewards transparency about backtest
  results and punishes hype hard.
- Respond to every comment personally within the day; this is a technical
  audience and unanswered questions read as evasive.

## Week 3 — proof over promise

- Short screen-recording (no voiceover claims beyond what's on screen) of:
  opening the research screen, toggling Simple/Advanced, running a backtest,
  reading the "Did any of it help?" table live in the app or terminal.
- Post to the same channels as a follow-up, framed as "here's the thing
  people asked about" — answering real Week 1-2 questions, not a second cold
  pitch.

## Week 4 — measure and decide

- Pull GitHub stars/clones/traffic (Insights tab), Instagram reach/saves,
  Reddit upvote ratio per post.
- Decide whether the primary positioning ("understand stocks without a
  finance background," via the research screen) is actually what's landing,
  or whether a different pillar (local-first AI, honest-by-construction) is
  pulling more engagement — let real numbers move the positioning, not
  guesses.

## Hard constraints across all four weeks

- Never post a specific return, win-rate, or profit number that isn't in the
  README's backtest table.
- Never post a screenshot of fabricated account performance.
- No paid engagement, no bought followers/upvotes, no fake reviews.
- If asked directly "does this make money," answer with the real backtest
  result, not a deflection.
